## 线路这一关怎么过

香港服务器的线路名词有两套常见说法，意思大致对得上。

一套按 BGP 品质分：**优质 BGP** 三网回程走国际段接驳，便宜；**精品 BGP** 三网回程尽量走内地骨干直连，延迟低、晚高峰更稳，贵一档；**国际 BGP** 纯国际选路，内地访问偏高，适合面向东南亚和海外。

另一套按优化方式分：**CN2/GIA 直连**，回程走电信 CN2 骨干，晚高峰延迟低、丢包少；**普通 BGP 国际线路**，白天流畅，晚高峰可能拥堵，价格便宜一大截；**单线优化**，只针对某一家运营商优化，受众集中在单一运营商时性价比反而高。

落到怎么选，看访客在哪：

- 八成以上访客在大陆 → 精品 BGP 或 CN2 方向，别省这一档的钱
- 访客在东南亚、欧美 → 国际 BGP 够用，为用不上的大陆优化付费是浪费
- 只要港区 IP 身份 → 住宅静态 IP，但要注意有些住宅 IP 产品明确写了“非大陆直连优化”，没有中转条件的人不该选

延迟量级参考：大陆到香港走优化线路普遍在 30–50ms，欧美机房动辄 200ms 以上。具体到商家，第三方测评给出的三网均值是华纳云约 41ms、恒创约 43ms、Jtti 约 40ms、V5.NET 约 48ms、ZJI 约 55ms，野草云自家口径是 60–95ms。这些数字来自不同商家、不同测试点、不同时间，不能拼成一个“香港服务器延迟”的结论，只能横向比个大概。

## 这几种情况，香港不是好选择

**游戏服务器**。香港节点对大陆四线 BGP 的调度精度不如大陆机房，游戏对战对抖动极敏感，移动网络下容易出现跳 Ping 和掉线，该用大陆 BGP 多线节点或全球加速。

**面向欧美的业务**。香港到欧美是 200ms 级延迟，第三方测评中华纳云独服的欧美节点实测就在 200ms 上下，单靠香港节点会明显偏慢，得配 CDN 或直接选美国机房。

**需要备案合规的国内业务**。香港免备案，买完就能绑域名对外服务，国内节点备案一般要 7–20 天。但免备案也意味着不适用大陆的备案与监管体系，合规要求高的业务还是该走国内节点。
